# 个人记账 App — 页面结构与交互设计 v1

> 只在本机浏览器运行，无登录、无联网。双击 `启动记账.bat` → 浏览器打开 `127.0.0.1` 页面。

---

## 1. 全局框架

```
┌──────────┬──────────────────────────────────────────────────────────┐
│ 记账本    │  页面标题            [◀ 2026年10月 ▶]      [+ 记一笔]  │
│          ├──────────────────────────────────────────────────────────┤
│ ▸ 首页    │                                                          │
│   账单    │                                                          │
│   统计    │                    页面内容区                             │
│   预算    │                                                          │
│   分类    │                                                          │
│   设置    │                                                          │
│          │                                                          │
│ 今日 ¥86  │                                                          │
└──────────┴──────────────────────────────────────────────────────────┘
```

- 左侧固定侧边栏 200px，六个入口，当前页高亮。
- 右侧顶部工具条：页面标题、月份切换（首页/统计/预算共用）、全局「+ 记一笔」按钮。
- 内容区最大宽度 1100px，居中，卡片式布局。
- 单页应用，切换页面不刷新浏览器；页面状态用 URL hash（`#/bills`），刷新后回到同一页。
- 侧边栏底部固定显示「今日支出 ¥86.00」。

**全局「记一笔」**：任何页面点它都弹出同一个记账弹窗，和历史默认值（上次用的账户、日期＝今天）。

## 2. 首页（快速记账 + 概览）

目标：3 秒内记完一笔。

```
┌────────────────────────────────────────────────────────────────────┐
│ 账户余额                                                            │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐                        │
│ │现金     │ │微信     │ │支付宝   │ │银行卡   │                       │
│ │¥ 320.00│ │¥1,180.5│ │¥ 642.30│ │¥8,400.0│                       │
│ └────────┘ └────────┘ └────────┘ └────────┘                        │
├───────────────────────────────────┬────────────────────────────────┤
│ 快速记一笔                         │ 本月概览                        │
│ ┌ 支出 ┬ 收入 ┬ 转账 ┐             │ 支出   ¥2,310.00               │
│ │       │       │       │          │ 收入   ¥8,000.00               │
│ │   ¥ 28.00  ← 大号金额输入        │ 结余   ¥5,690.00               │
│ │                                   │ 预算剩余 ¥1,690 / 4,000        │
│ │ 分类（图标网格，常用在前）         │ ▓▓▓▓▓▓▓░░░ 57%                │
│ │ [餐饮][交通][购物][娱乐]…          ├────────────────────────────────┤
│ │ [更多分类 ▾]                      │ 今日已花 ¥86.00 · 3 笔          │
│ │                                   ├────────────────────────────────┤
│ │ 账户 [微信 ▾]   日期 [今天 ▾]     │ 最近记录            [查看全部]   │
│ │ 标签 [朋友×][报销×][+ 添加]       │ 12:30 餐饮/午饭  -28.00 微信    │
│ │ 备注 [                     ]      │ 09:10 交通/地铁  -6.00  微信    │
│ │                                   │ 昨天  工资      +8,000 银行卡   │
│ │            [ 保存 (Enter) ]       │                                │
│ └───────────────────────────────────┴────────────────────────────────┘
└────────────────────────────────────────────────────────────────────┘
```

**交互规则**

1. 三个 tab 用快捷键 `Alt+1/2/3` 切换；打开页面时金额框自动聚焦，直接敲数字。
2. 支出/收入：金额 → 分类（点选，二级分类在网格里以「餐饮 · 午饭」形式平铺，最常用的最多 12 个）→ 账户（默认上次使用的）→ 日期（默认今天，可点开日历）→ 标签（多选，输入即时创建新标签）→ 备注。**保存后清空金额和备注，保留分类、账户、日期**，方便连续记多笔。
3. 保存成功：右下角 toast「已记录 −¥28.00 餐饮 · 午饭」，最近记录顶部插入新行，账户余额与本月概览立即更新。
4. 转账：变成 `从 [微信 ▾] → 到 [银行卡 ▾]` + 金额 + 备注；**不计入收支统计**，两边余额同步变化。余额不足时黄色提示「微信余额剩 ¥20.00」，但不阻止保存。
5. 金额输入框只接受数字和一个小数点，最多两位小数，回车即保存。
6. 校验：金额 > 0、分类必选、账户必选；不满足时对应字段下方红字提示，不弹窗打断。
7. 空状态：账户未创建时显示「先建一个账户」引导；无记录时最近记录区显示「还没有账目，从上面记第一笔吧」。

**交互规则**

4. 金额颜色：支出红 `−¥28.00`、收入绿 `+¥8,000`、转账灰并显示箭头 `微信 → 银行卡`。

6. 按日期分组，组头右侧显示当日合计；组默认展开。
7. 列表一次加载 50 条，底部「加载更多」。
8. 筛选无结果：显示「没有符合条件的账目」+「清空筛选」按钮。
9. 汇总条随筛选实时变化，清楚当前筛出来的合计数。

## 5. 预算管理

```
┌────────────────────────────────────────────────────────────────────┐
│ ◀  2026 年 10 月  ▶                              [编辑预算]         │
│ ⚠ 本月已有 2 个分类超支：餐饮、娱乐                                  │
│ ┌────────────────────────────────────────────────────────────────┐ │
│ │ 本月总预算                       已用 ¥2,310 / ¥4,000           │ │
│ │ ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░  58%          剩余 ¥1,690                  │ │
│ └────────────────────────────────────────────────────────────────┘ │
│ 分类预算                                                            │
│ 餐饮      ¥1,040 / ¥1,000   ▓▓▓▓▓▓▓▓▓▓▓▓ 104%  超支 ¥40    [改]    │
│ 交通      ¥  462 / ¥  500   ▓▓▓▓▓▓▓▓▓░░░░  92%  剩 ¥38     [改]    │
│ 购物      ¥  415 / ¥  600   ▓▓▓▓▓▓░░░░░░░  69%  剩 ¥185    [改]    │
│ 娱乐      —     / ¥  200   ▓░░░░░░░░░░░░   0%  剩 ¥200    [改]    │
│ 医疗      未设预算                                          [设预算]│
└────────────────────────────────────────────────────────────────────┘
```

**交互规则**

1. 总预算与每个一级分类的预算都可单独设置，留空＝不设。
2. 进度条配色：< 80% 绿色；80–100% 黄色；> 100% 红色并显示「超支 ¥X」。
3. 超支提醒出现在三个位置：预算页顶部黄条、首页概览区红字、侧边栏预算入口小红点。
4. 分类预算只统计该一级分类及其所有二级分类的支出。
5. 预算按月存储，切换月份看到的是那个月的历史预算，改预算只影响当月。
6. 编辑预算用行内输入框，回车保存，Esc 取消。
7. 没有设置任何预算时，显示引导「设一个本月预算，超支时提醒你」。

## 6. 分类管理

```
┌────────────────────────────────────────────────────────────────────┐
│ 支出分类 / 收入分类            [ + 新建一级分类 ]                    │
├────────────────────────────────────────────────────────────────────┤
│ ▾ 🍜 餐饮        12 项    18 笔        [编辑] [停用] [↑][↓]         │
│      · 早饭       4 笔   [编辑] [删除]                              │
│      · 午饭       8 笔   [编辑] [删除]                              │
│      · 外卖       6 笔   [编辑] [删除]                              │
│      · + 添加子分类                                                 │
│ ▸ 🚇 交通         5 项     9 笔        [编辑] [停用] [↑][↓]         │
│ ▸ 🛍 购物         3 项     4 笔        [编辑] [停用] [↑][↓]         │
│ ▸ 🎬 娱乐         2 项     0 笔  (已停用)  [启用]                    │
└────────────────────────────────────────────────────────────────────┘
```

**交互规则**

1. 一级分类可展开/收起，二级分类缩进显示；只支持两级，二级下不能再加。
2. 新建/编辑弹窗字段：名称、图标（预置图标集选取）、颜色、所属一级（仅二级）、类型（支出/收入）。
3. 删除规则：没有任何账目引用 → 直接删（二次确认）；有引用 → 弹窗要求选择「停用」或「把这些账目转移到其他分类」。
4. 停用的分类不再出现在记账选择器里，但历史账单和统计里照常显示，带「已停用」灰色标记。
5. 排序用上移/下移按钮（第一版不做拖拽），顺序决定记账页分类网格的排列。
6. 一级分类改名不影响二级，「转移账目」会一次性改掉所有引用。
7. 计数（N 项 / M 笔）让用户知道删改的影响范围。

5. 清空数据：二次确认 + 输入「清空」，执行前自动写一份备份文件。

## 8. 通用交互规则

| 场景 | 行为 |
|---|---|
| 保存 | 所有改动即时写盘，按钮只用于提交表单；不需要“保存设置” |
| 删除 | 一律二次确认，文案说明影响（如「删除这笔 ¥28.00 的支出？」） |
| 反馈 | 右下角 toast，3 秒自动消失，成功绿 / 失败红 |
| 弹窗 | Esc 关闭；有未保存内容时提示确认；点击遮罩先确认再关 |
| 表单 | 必填项标 *，错误信息在字段下方红字，不阻塞输入 |
| 金额 | 统一两位小数，显示带千分位 `¥1,234.56`，负数用红色 |
| 键盘 | Enter 提交表单，Esc 关闭弹窗，Alt+1/2/3 切换收支/转账 |
| 服务异常 | 若本地服务没启动，页面显示「本地服务未连接，请双击 启动记账.bat」并给出重试按钮 |
| 空状态 | 每个模块都有对应的引导文案和下一步按钮，不留白屏 |
| 数据安全 | 每次写盘前先写临时文件再替换；启动时保留最近 20 份历史副本 |

## 9. 数据结构草案

```json
{
  "version": 1,
  "accounts": [
    { "id": "a1", "name": "微信", "icon": "💬", "color": "#2ecc71",
      "initialBalance": 0, "archived": false, "order": 1 }
  ],
  "categories": [
    { "id": "c1", "name": "餐饮", "parentId": null, "kind": "expense",
      "icon": "🍜", "color": "#e67e22", "archived": false, "order": 1 },
    { "id": "c2", "name": "午饭", "parentId": "c1", "kind": "expense",
      "icon": "", "color": "", "archived": false, "order": 1 }
  ],
  "tags": [ { "id": "t1", "name": "朋友" } ],
  "transactions": [
    { "id": "x1", "kind": "expense",        // expense | income | transfer
      "amount": 2800,                        // 单位：分
      "accountId": "a1", "toAccountId": null,
      "categoryId": "c2", "date": "2026-10-18",
      "note": "和同事吃饭", "tagIds": ["t1"],
      "createdAt": "2026-10-18T12:31:00+08:00",
      "updatedAt": "2026-10-18T12:31:00+08:00" }
  ],
  "budgets": [
    { "month": "2026-10", "total": 400000,
      "byCategory": { "c1": 100000 } }
  ],
  "settings": { "defaultAccountId": "a1", "monthStartDay": 1, "overspendAlert": true }
}
```

- 金额一律用「分」存整数，避免浮点误差，展示时再除以 100。
- 账户余额 = 初始余额 + 收入 − 支出（转账不计入收支，但对两个账户余额分别加减）。
- 删除采用物理删除（个人单机场景），配合历史副本兜底。

## 10. 视觉基调

- 浅色背景 `#f6f7f9`，内容卡片纯白、圆角 12px、轻阴影。
- 主色蓝绿 `#2f80ed`；支出红 `#e5484d`，收入绿 `#1a9c62`。
- 中文字体：微软雅黑 / 系统默认；数字用等宽或 `tabular-nums`，金额右对齐。
- 分类一律「彩色图标 + 名称」，同一分类在记账、账单、统计里图标颜色保持一致。
- 不引入任何外部 CDN、字体、图表库；全部本地文件，断网可用。

## 11. 已确认的决策（2026-10-21）
