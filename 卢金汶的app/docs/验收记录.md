## exe 版本一致性验证

| 项目 | 结果 |
|---|---|
| 编译产物 | `记账本.exe`，249 KB，内嵌 38 个前端资源与默认数据 |
| 编译方式 | `tools\build-exe.ps1`（Windows 自带 csc，无需安装 .NET SDK） |
| 接口与存储（exe 版） | 43/43 通过（`tests\api.tests.ps1 -ServerExe 记账本.exe`） |
| 界面与流程（exe 版） | 36/36 通过（内部含 71 项单元 + 96 项流程） |
| 启动耗时 | 首次 220 ms，重启 96 ms（优化后；优化前 3.7 s） |
| 数据位置 | exe 同目录 `data\`，与 `.bat` 版本共用同一份数据 |
| 单文件性 | 只依赖 .NET Framework 4.x（Windows 10/11 自带），不需要其他运行时 |

优化记录：最初的实例检测会对 8611–8620 逐端口发起 HTTP 探测，在关闭端口上每次等待约 300 ms，导致启动慢 3 秒；改为「先试绑定端口，仅在被占用时才发 HTTP 请求」后，正常启动不再有任何网络等待。

## 已知限制（不影响第一版验收）

1. **每月起始日固定为 1 日**，设置页只展示不可改；跨月口径按自然月计算。
2. **统计折线图的累计口径**由 `selectors.js` 计算，测试覆盖了数据聚合，未逐像素校验曲线形状。
3. **CSV 的 Excel 兼容性**已用本机 Excel 实测；Excel 会把 `28.00` 显示为数字 `28`，数值本身正确。
4. **不会自动打开浏览器**的情况：若默认浏览器未正确关联，需要手动访问窗口里显示的地址。
